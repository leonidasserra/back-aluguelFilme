## Visão Geral

Back-aluguelfilme é um backend baseado em Spring Boot desenvolvido especificamente para gerenciamento de aluguel de filmes, com foco em segurança, escalabilidade e arquitetura limpa. Integra autenticação Firebase/SQL, APIs RESTful e foi arquitetado e desenvolvido para gerenciar diversas operações de negócio de forma eficiente.

### Por que back-aluguelfilme?

Este projeto simplifica os processos de aluguel de filmes com um backend robusto para sistemas de locação. As principais funcionalidades incluem:

- ⚙️ **Segurança**: Implementa autenticação e autorização baseada em JWT para acesso seguro aos recursos.
- 🎬 **Melhores APIs**: Define entidades principais como *Filme*, *Aluguel*, *Usuário* e *Avaliação* para gerenciamento estruturado de dados.
- 📊 **Módulos Principais**: Combina tratamento de exceções, melhorando confiabilidade e depuração.
- 🔧 **Fácil Acesso**: Implementa filtragem de dados com API Predicate.
- 🏗️ **Escalabilidade**: Projetado para desenvolvimento backend escalável e de fácil manutenção.
